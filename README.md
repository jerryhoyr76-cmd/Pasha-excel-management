# 📊 Excel Student Manager

A simple static web app to manage student records using Excel import/export.  
Built with HTML, CSS, and JavaScript — no backend required!

---

## 🚀 Features
- ➕ **Add Student**: Manually add new student records.
- 📥 **Import Excel**: Load data from `.xlsx`, `.xls`, or `.csv` files.
- 📤 **Export Excel**: Download current records as an Excel file.
- 🌐 **Deploy Anywhere**: Works perfectly on **Netlify**, **Vercel**, or **GitHub Pages**.
- ⚡ **Static App**: No database or server required. Data resets when the page is refreshed.
